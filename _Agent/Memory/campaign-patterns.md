# Campaign Patterns

## Campaign Tone & Style
- **Genre:** Nautical fantasy with horror/eldritch elements
- **Tone:** Gritty mercenary work with morally ambiguous choices
- **Setting:** Port city of Laguna Nera with underworld economy; islands with ancient threats

## Recurring Themes
1. **The Electrum Economy** - Underworld operates on Electrum (~10 gp value), separate from standard gold economy
2. **Information Brokers** - Knowledge is power; Denjin Karr and others trade in secrets
3. **Ancient Aquatic Threats** - Karkinos, Zalzigarath, sea monsters represent old powers
4. **Morally Flexible Mercenaries** - Party works for coin, reputation matters more than alignment

## Session Structure Pattern
1. Job acceptance / quest hook (often from Denjin Karr)
2. Travel sequence (sea voyages, storm challenges)
3. Discovery/exploration (villages, caverns, ritual sites)
4. Combat encounter with tactical elements
5. Escape/chase sequence
6. Economic/moral decision point (deliver vs. betray, gold vs. electrum)

## DM Patterns
- Uses skill challenges for chase/escape sequences
- Environmental hazards are common (storms, waterfalls, unstable terrain)
- Enemy encounters often have "boss" arrivals that force retreat
- NPCs have multiple aliases and transcription-prone names
- Magical surveillance is a recurring element (tarot card scrying)

## Economic Reference
| Currency | Value | Usage |
|----------|-------|-------|
| Gold Piece (gp) | Baseline | Standard economy |
| Electrum | ~10 gp each | Underworld economy (Silver Purse, Velvet Dreams) |
