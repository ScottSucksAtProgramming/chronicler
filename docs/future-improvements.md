# Future Improvements

- Semantic duplicate-prose cleanup for imported descriptions. Structural clutter is fixed, but repeated imports with differently worded summaries can still leave redundant paragraphs.
- Image ingest support for multimodal models.
- Office and tabular source adapters for `.docx`, `.pages`, `.csv`, and `.xlsx`.
- Additional conservative relationship inference rules where deterministic evidence is strong enough to avoid unnecessary questions.
- Optional review/reporting views for relationship gaps so batch triage is easier without changing the deterministic `improve` workflow.
